2 — Context

Context は、問いから辿った、グラフの一つの射影

何をする
根から型のある線を、決まった規則で辿る。同じ入力なら同じ出力
どこにある
cargo xtask context --root <ID> --at <rev>
Agent は
context-audit組み立てない。食い違いや古い前提を「要確認」で返す
次へ
八つの項目の要約を持って、Design Space へ

amber の輪が根の問い。照らした範囲だけが Context に入る

  1. 今回決めること
  2. 守る制約
  3. 現在案の理由
  4. 別案と採らなかった理由
  5. 弱まった前提
  6. 未解決の問い
  7. 見るべき作例
  8. 欠けている文脈
