3 — Implementation

PR には、体験の差と、確かめた範囲と、戻し方を書く

PR
設計上の変更
一覧の環の外径を揃え、閉じ具合で示す
体験の差
並べても、大きさで序列が生まれない。録り始めの音源も小さく見えない
確認した範囲
描画・焦点・状態遷移は自動で確認した。初めて見る人の読み方は未確認で、人の確認待ちにある
戻し方
一覧の表し方を一つ戻せば、比例の表示に戻る

比べた案は PR の履歴に残り、採った状態だけが stable の story へ移る

  1. 実装外径を揃える実装と、四つの欄の下書き。確認した範囲は Receipt から写す
  2. CI参照と仮説と、どこまで走らせたかを検査する
  3. 人下書きを直し、統合して出荷する
  4. 未確認の行Agent には消せない
