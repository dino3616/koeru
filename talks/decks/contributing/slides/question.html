2 — Question

良い問いは、答えを埋め込まず、作るものを分ける

何をする
判断を進められる問いにして、閉じる条件を持たせる
どこにある
meta/questions/
Agent は
frame重なりと不足を探し、候補を少しだけ出す
次へ
Context の根になる

良い問いの六つの条件

  1. 答えを先に入れない
  2. 論点は一つ
  3. 誰が、どの場面で
  4. 症状ではなく、目指す状態に向ける
  5. 答え次第で、作るものが変わる
  6. 開く問いと閉じる問いを、段で使い分ける
開く問い ／ 案を開く 「何で、〜を伝えるか」「何が、〜を止めているか」
閉じる問い ／ 案を比べ終えて、確かめる段で 「この案で、〜を見分けられるか」
