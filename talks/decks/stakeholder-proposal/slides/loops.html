コミュニティの未来 3 / 3

幹線が通ると、四つの輪が回り始める

  1. Product — 制作の輪 ・ 回すのは音源を作る人

    試唱 → 気になる点が分かる → 録り足す・直す → 変化を聴く

    成り立つ条件: 試唱が驚きで終わらず、次の判断に結びつくこと

  2. Community — コミュニティの輪 ・ 回すのは支える人

    誰かの失敗 → 再現例 → 手順が直る → 次の人の失敗が減る

    成り立つ条件: 一人が全部の質問を抱えないこと

  3. Creator to Creator — 作り手から作り手へ ・ 回すのは音源を使う人

    任意で渡した声 → 別の人の作品 → 反応が作った人へ戻る

    成り立つ条件: 公開も利用も強いないこと。規約・導入・返し方が明確なこと

  4. Standardization — 互換の輪 ・ 回すのはツールを作る人

    再現できる出力 → 他の道具で確かめる → 独立に採用される → 互換が定着する

    標準とは、シェア一位のことではない。他の人が説明でき、他の実装で扱え、作者がいなくても検証できること
