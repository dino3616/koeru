# マイルストーン

要件はちょうど1つのマイルストーンに属する。 どこにも属さない要件は誰も作らないまま残り、
二重に属すると二度作るかどちらもやらない。`cargo xtask check-meta` が検査する。

この表は手で数えている。 実体とずれたことがあるので、直すときは
`cargo xtask check-profile PROFILE-<ID>` の出力と突き合わせる。

| | 何を終わらせるか | 要件 | 塞いでいる未決 |
|---|---|---:|---:|
| M1 | 仕様の食い違いを閉じる。コードは書かない | 2 | 0 |
| M2 | 録って、聴ける（単独音 / Windows と macOS / 1曲） | 122 | 2 |
| M3 | 自動原音設定が成立するか | 29 | 0 |
| M4 | 手渡せる形にする | 32 | 0 |
| M5 | 方式を広げる | 26 | 0 |
| M6 | 原音設定エディタ | 52 | 3 |
| M7 | 配る | 14 | 1 |

M2 は判断記録の撤回条件に触る未決を並行で確かめる。 miniaudio の到達性、WebView の
常駐メモリ、SwiftF0 のコーパス、試唱の最短長。ここが崩れると後続がやり直しになる。

## 検査

```bash
cargo xtask check-profile PROFILE-M2
```

未決の論点が塞いでいる間は落ちる。通常の CI では走らせない。 未決が残っているのは
着手前は正常で、その状態で「終わった」と言うのが異常だという線引きにしている。
実行は `.github/workflows/release-gate.yml`（手動）。

## 未決が閉じたら

論点の `status` を `closed` にするのではなく、**判断が付いたなら `meta/decisions/` へ移して
論点ファイルを消す。** 経緯は git が持つ。要件が足りなかったなら `meta/requirements/` へ
書き足す。どちらでもないなら、それはまだ閉じていない。
