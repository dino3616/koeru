# ブランドの方向

`docs/design/redesign-plan.md` の Phase 4。判断は `DEC-PLT-025`（画面の重心と視覚言語）と `DEC-PKG-007`（完成の関門）。ここは読みどころ。

`docs/product-vision.md` の Tone と Naming は上位にある。ここで作るのはその視覚化であって、新しいブランドの発明ではない。

## 目指しているのは、ゲームのキャラクリエイトの感覚

中央に作っているものがいて、周りが操作で、触るたびに反応が返る。

**現行の画面も、質感を差し替えるだけの案も、どれも作業画面だった。** 次に読む文字があって、押す的があって、結果が下に並ぶ。キャラクリはそうではない。

この読み替えは方針と噛み合う。録音の途中でも歌が聴けるのはリアルタイムプレビューそのもの、カバレッジと歌える曲が増えるのはステータスが育つこと、Own your voice は所有感のこと。**言い換えただけで、新しいことは何も足していない。**

## 環は、声の形であり音の地図でもある

単独音の録音リストは子音行が揃うように生成される（`TR-RCL-03`）。だから被覆を同心の環として描くと、あ行・か行・さ行……が環になり、閉じ具合がそのまま被覆になる。**声の形と音の地図が同じ図になる。**

中央の「聴く」はいつでも押せて、押すたびに歌う。録るほど、同じ曲がちゃんと歌えるようになる。

## 評価しないから、夢中になれる

`TR-SYN-20` が品質スコア・良し悪しの判定・他音源との比較・上達度を禁じ、`DEC-REC-008` が観測をフラットに報告するだけと決めている。**スコア、ランク、実績、比較は出せない。**

これは制約に見えて、実は同じ方向を向いている。**キャラクリが楽しいのは、評価されないから。** 誰も「あなたの顔は72点」と言ってこない。環が閉じるのは「うまくなった」ではなく「録った」で、収録量の表示でしかない。

## いじれるのは、声の表情

キャラクリはパラメータをいじれるから楽しい。KOERU で本人がいじれるものは、採用テイクの切り替えにした。

世代は既に積まれていて（`TR-REC-21`）、切り替えても被覆は変わらない（`TR-RCL-25`）。**壊れない操作なので、恐れずいじれる。** 同じ音の別の録り方を選ぶことが、声の表情を選ぶことになる。

## 声の色は本人のもの、ブランドの色は固定

音高帯・共鳴の重心・発声の長さから、色相・彩度・明度を決定的に作る。録るほど更新される。

**UI のアクセントは固定で、声の形の色だけが音源ごとに変わる。** ブランドは本人の声の色を名乗らない。

ロゴは同じ視覚言語で、別に起こす。 生成規則のインスタンスにはしない——KOERU には声が無いので、規則へ通す入力を作為的に決めることになり、「声から生まれた」という物語がかえって薄くなる。環・曲線・線質という語彙を共有しつつ、ブランドの形と本人の声の形が同じ列で混ざらないようにする。

## 完成は、環が閉じることで表す

環が表すのは `TR-PKG-34` の3条件のうち被覆だけなので、そのままでは環が閉じても完成しない状態が作れてしまう。`DEC-PKG-007` で条件を先に満たさせることにした。**被覆が満ちた瞬間には必ず完成している**ので、別の印を足さずに済む。

名前は必須にし、あとから変えられるようにした。 表示名は完成の条件なので未設定のまま通せない。一方 `UC-F01-02` は「名前で止まらない」ことを求めている。**仮の名前で通過でき、気が変わったら変えられる**なら、判断を求められていない。

## 実装で踏むもの

**声の形は SVG で描く。canvas では描かない。** 強制カラーモードでは OS が CSS の色だけを差し替え、canvas へ描いたピクセルには触らない。図が元の色のまま取り残される。`globals.css` に既に記録がある落とし穴で、波形と原音設定の線について書かれているものが、そのままここにも当たる。

環が伸びる演出には `prefers-reduced-motion` の経路が要る（`TR-PLT-33`）。連続収録（`TR-REC-20`）では数秒ごとに確定するので、動きは短くする。

## 引き受けたリスク

**彩度と明度に差が出ると、優劣に見える余地が生まれる。** 色相は一周するので優劣が無いが、彩度と明度は素直に強弱として読まれる。`TR-SYN-20` が禁じているのは比較を製品が出すことで、利用者が推し量ることまでは禁じていない。違反ではなく残存リスクとして引き受けた。撤回条件は `DEC-PLT-025` にある。
