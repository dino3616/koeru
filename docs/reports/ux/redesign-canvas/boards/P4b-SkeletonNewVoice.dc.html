骨格 — 新しい音源から収録まで

音源の中にサブバンク（方式 × 声色 × 収録音階）を複数持てるようにしたときの、「＋ 新しい音源」から S04 までの骨格。表層（色・文字の大きさ）はまだ決めない。
前提 — 構造（OOUI）
音源1—n→サブバンク1—n→行1—n→テイク
音源音源名・フォルダ名・色・画像。サブバンクが 0 でも存在できるサブバンク方式 × 声色 × 収録音階。この3つの組が音源の中で重複しない方式単独音 29行 · 連続音 261行 · CVVC 131行　方式が録音リストを決める声色自由入力。空欄は「声色なし」（単一の声色の音源）収録音階C1–B7。多くは C3–C5 なので、そこを最初に見せる
この流れで満たすこと
戦略：最初の行を録り始めるまでを最短にする。構成を決めきれていなくても録り始められる。
要件：1画面でサブバンクの枠を何個でも並べられる。同じ方式・声色の音階違いを素早く足せる。
構造：「新しい音源」は音源をすぐ作る操作。入力の途中で閉じても、音源と枠は残る（下書きにしない）。
いまの画面との差：S01 音源名 → S02 方式（1つ）→ S03 の3画面を、1画面（音源の設定）＋ 条件つきの S03 にする。
歩いて確かめる — 「＋ 新しい音源」から最初の行まで
操作 1「＋ 新しい音源」サイドバー・⌘N・メニュー。押した瞬間に「新しい音源 3」が木に増え、本文は「音源の設定」になる
操作 2音源名入力欄にフォーカス済み。仮の名前のまま Tab で進んでもよい
操作 3–5最初の枠方式・声色・収録音階。既定は CVVC ・空欄・A3 で、触らなければ 0 操作
操作 +1 / 枠枠を足す「同じ方式・声色で音階を足す」は 1 操作（⌘D）。別の方式は「＋ 枠」から
操作 6収録をはじめる⌘↵。先頭の枠から録る。並び順＝収録順（ドラッグで並べ替え）
到達S04 収録パンくず「新しい音源 3 › CVVC A3 ▾ › 収録」。▾ で別の枠に切り替え
最短は ⌘N → ⌘↵ の2操作（仮の名前・CVVC・A3 の枠1つ）。名前・枠の中身・枠の数は、S04 に入ったあとも同じ「音源の設定」で変えられるので、ここで決めきらなくてよい。

1サイドバーに即座に出る　押した時点で音源ができる。木の中に、つくった枠がそのまま子として並ぶ。閉じても消えない
2音源名　フォーカス済み・全選択。フォルダ名（ASCII）は名前から自動で、ここには出さない
3方式　3択のセグメント。枠ごとに選べる（1つの音源に複数の方式が並んでよい）
4声色　自由入力。この音源で使った声色を候補に出す。空欄は「声色なし」
5収録音階　押すと音階ピッカー（右下）。1枠 = 1音階。重複する組は行の枠を琥珀にし、収録をはじめるを止める
6枠を足す　「＋ 枠」は空の枠、⌘D は選んでいる枠の方式・声色のまま次の音階を候補にした枠
7収録をはじめる　先頭の枠から。行の並び＝収録順。枠が 0 または重複があるときは押せない
8合計　行数と所要時間は方式から計算。入力デバイスは前回のものを事実として出すだけ

A　行（表）採用
1枠＝1行。7枠でも縦に収まり、Tab で横に進める。同じ方式・声色が上下に並ぶので重複と抜けが目で追える。S06 の一覧・サイドバーの木と同じ並びになる。
B　カード不採用
1枠に鍵盤まで載せられるが、枠が増えると画面を越える。比べる軸（方式・声色・音階）が揃わず、重複に気づきにくい。

C　掛け合わせ補助として
方式 × 声色 × 音階を選ぶと全組み合わせが出る。2×2 は速いが、例の「連続音は Whisper C5 だけ」のような構成では外す手間が増える。A の上に「まとめて足す」として置く余地はある。

S04 収録（到達点）
先頭の枠で始まる。パンくずの ▾ で同じ音源の別の枠に移る。枠の中身を変えたくなったら、サイドバーの木から「音源の設定」に戻る。
状態と例外
枠が 0「収録をはじめる」を押せない。音源だけ先に作っておく使い方はできる
組が重複該当の2行の枠を琥珀に。行の右に「CVVC Whisper A3 と同じ」
声色が空欄の枠が2つ以上同じ方式・音階なら重複。違えば可（例：CVVC A3・CVVC G4）
途中で閉じた／別の場へ移った音源も枠もそのまま残る。サイドバーの木から戻れる
収録済みの枠を変える方式は変えられない（録音リストが変わるため）。声色・音階は名前の付け替えとして変えられる
枠を消す未収録ならすぐ消える。収録済みなら確認を出す（テイクごと消えるため）
