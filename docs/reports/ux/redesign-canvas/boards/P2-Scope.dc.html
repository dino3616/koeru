02 / SCOPE

要件 — 画面が背負うもの

有バックエンドにある 型スキーマのみ（M6） 無まだ無い・提案
入口
有音源をつくる。音源名は既定のまま通過できる
有方式3種と収録音階。行数・エイリアス数・所要時間を併記
有入力デバイスの固定・ゲイン調整・ガイドBGM の回り込み確認・残量見積もり
無マイク許可の要求と、拒否からの復帰手順
無中断したテイクの復旧候補を採る／捨てる
収録
有録音リストの次の行を大きく出す。基準音を鳴らす
有テイクは上書きせず積み、新しいものを採用。いつでも戻せる
有収録順「曲バンク優先／被覆効率」。可逆、常に表示
有カバレッジと試唱できる曲数、残りの時間と行数
無収録中のガイドBGM（クリックと持続音）、連続収録の自動送り
試唱・曲バンク
有4秒以上つながれば試唱できる。最初の音は6秒以内（中央値）
有UST / USTX を2段で取り込む（中身を見てから題を決める）
有曲に合わせて録音リストを詰め直し「あと録る行」を出す。ノート範囲でも可
有キーは手動で ±12。自動移調はしない
無試唱を短い動画・音声として書き出して共有する
原音設定
有自動原音設定のあと、確認が要るエイリアスだけを並べる。合計5分まで、1件約10秒
有通常モードは「これで良い／ずれている」と境界1本
有手で直した値は固定。再推定しても上書きしない
型上級モード：5値、スペクトログラム、一括編集12種、undo
無そのエイリアスが鳴る曲の一節で試唱する（試唱して気づく、を前に倒す）
配布
有character.txt / yaml の項目・アイコン・立ち絵・規約・readme を1か所で
有書き出せない理由を全件、該当の行・エイリアスへ1操作で飛べる
有UTAU / OpenUtau / 両方。ZIP と UAR。読み戻し検証
有リリース記録と、連続音から単独音版を別に出す
無規約の章立てテンプレート（自由記述欄の入力補助）
横断する要件
無コマンドパレット（⌘K）。すべての操作を名前で呼べる
無利用計測とクラッシュ報告の同意。別々、既定オフ、最初のテイクの後に1回だけ
有失敗の型 → 次の一手（class → action）。文言を解析しない
有壊す操作の前の自動スナップショット（直近20件）
有音源の顔：キャラクター画像（アイコン・立ち絵）を最初から登録でき、無いあいだは声の色と頭文字で代替する。声の色は OKLCH、赤と琥珀を除く
無ネイティブの作法：メニューバー、ファイルのドロップ、OS 通知、ファイラで表示、ウィンドウの最小サイズ
内容要件 — UTAU の標準語彙をそのまま使う
言い換えると、KOERU の外（wiki・配布ページ・OpenUtau）で通じない言葉を覚えさせてしまう。標準の語彙は曲げずに使い、初めて出る場所で短い説明を添える（ⓘ・ホバー・読み上げ）。
音源 収録 録音リスト 単独音／CVVC／連続音 多音階・収録音階 ガイドBGM テイク 原音設定 エイリアス oto.ini 左ブランク・固定範囲・右ブランク・先行発声・オーバーラップ 試唱 配布パッケージ character.txt・readme.txt・規約 アイコン・立ち絵
KOERU 固有の語は2つだけ：カバレッジ（必要なエイリアスのうち録れた割合）と曲バンク（目標にする UST の集まり）。
通常モードと上級モードの違いは語彙ではなく、触れる値の数（境界1本 ⇔ 5値すべて）。
使わない語：「小さすぎます」「割れています」などの評価、「全自動」の断言。
非目標
— 配布の場・音源を見つける機能（手渡しは ZIP まで） — 公開したかどうかで完成や進み具合を判定する — 声をサーバへ送る処理、アカウント — ニューラル音源のデータセット形式 — DAW のような曲の編集（歌わせる確認に留める） — 自動移調、自動でのマイク切り替え — 日本語以外の UI（初期スコープ外） — 機材や場所がない人への解決（要件として外に置く）
要判断実装とビジョンの食い違い・未決事項（この案での扱い）
単独音の所要時間 — ビジョンは約8分、生成器は 847 秒（約14分）。画面は生成器の値を出す（S02）。
マイク準備の手数 — 「4操作で最初のフレーズ」と、録音開始の前提（選択・調整・生死・残量）が衝突。準備を1画面・1操作に畳み、調整は最初のひと声で兼ねる（S03）。
収録音階は録り始めたら増やせない — 選ぶ時点で「あとで増やせない」と明記し、単音階で始める推奨を最上段に置く（S02）。
「作り込む」に当たる方式が無い — 方式としては出さず、原音設定の上級モードへの入口として表現する（S02 / S09）。
上位の方式へ移る経路 — 未決。音源のページに場所だけ確保し、今回は描かない。
計測の同意 — バックエンドに無い。最初のテイク後の小さな通知として描く（S04）。
