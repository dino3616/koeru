05+ / ADVERSARIAL REVIEW

敵対的検証 — 存在声域は、どのキャラクターにも敬意を払えるか

UTAU には年齢・性別・種族・画風がまったく違うキャラクターがいて、キャラクターを持たない音源もある。立ち絵は絵師に依頼したものも多く、規約で改変・加工・加筆を禁じている例もある（トリミングや拡大縮小は許す、など）。性質の違う8体の架空キャラクターで「はじめての試唱」の瞬間を描き、UI がキャラクターを上書きしていないかを確かめる。
検証の基準
C1
絵に手を入れない
切り欠き・角丸・網点・重ね描き・ぼかしをしない。比率と透過を保つ。拡大縮小だけ。
C2
色の主導権はキャラ
イメージカラー（本人が選ぶ）＞声の色。面は塗らず、線と光の1点だけ。
C3
名前に人格を足さない
名前は UI 書体で組む。ロゴ画像があればそれを変形せずに置く。
C4
祝福の温度は中立
煽る文言・ステッカー・跳ねる動きを使わない。表情は歌と立ち絵に任せる。
C5
キャラが無くても成立
画像が無い音源を「未設定」に見せない。キャラクターを勝手に作らない。
C6
属性を前提にしない
性別・年齢・種族で分けた語やプリセットを置かない（S02 の音域プリセットは撤去済み）。

C. 小さな顔（サイドバー 24px）でも同じ規則
{{c.initial}} {{c.short}}
アイコン（UTAU では 100×100 の正方形）があればそのまま縮小し、角丸もかけない。アイコンが無いときに、立ち絵から顔を自動で切り出すことはしない（勝手なトリミングになる）。代わりに、イメージカラーの細い枠と頭文字を UI 書体で置く。
D. 判定と、修正案に残るリスク
いまの存在声域修正案 C1✕ 切り欠き・網点・ステッカーが絵に乗る○ 拡大縮小だけ。ドット絵は整数倍、背景付きは角丸なしの枠 C2✕ 声の色で面を塗る○ 本人が選ぶイメージカラーを線と進行にだけ。暗い色は明度だけ上げる C3✕ 名前を Dela Gothic と斜体で組む○ UI 書体、ロゴ画像があれば変形せずに置く C4✕ 「はじめまして」「完成」の高揚○ 「はじめての試唱」と事実だけ。表情は歌と立ち絵に任せる C5△ 代替が KOERU 風の網点の紙面○ 無彩のタイルに頭文字。キャラ風の演出をしない C6✕ 女声／男声のプリセット○ 方式と音階を直接選ぶだけ（S02 修正済み）
表情差分が多い立ち絵 — どの1枚を使うかは本人が選ぶ。KOERU は場面ごとに表情を選ばない。 イメージカラーの自動候補 — 立ち絵から候補を出すのは補助まで。誤った抽出で人物像を塗り替えないよう、確定は本人。 KOERU の印象が弱くなる — 引き換えに、ブランドは ⌘K・キー操作・精度・ワードマークで出す（Arc / Linear と同じ置き方）。 ダークの舞台が合わない画風 — 白背景前提の淡い水彩などは沈む。舞台の明るさ（ダーク／グレー／ライト）だけは本人が選べるようにする案を次に検証する。
