骨格 — 収録の中で歌う

S05「はじめて歌う」を消し、どの曲が歌えるか・あと何行か・歌えるようになった瞬間・曲の再生と停止を S04 の中に置く骨格。表層はまだ決めない。
この骨格で満たすこと
戦略：録った声が歌になる瞬間を、録る手を止めずに起こす。S05 は全画面の別の場で、聴いたあとに収録へ戻る1手が要った。
要件：S04 の中で ① どの曲が歌えるか ② あと何行で歌えるか ③ 歌えるようになった瞬間 ④ 曲の再生・停止 がそろう。
構造：曲 n—n エイリアス。いまのサブバンクが属する「声色 × 方式」で、曲の全ノートのエイリアスがそろえば「歌える」。音階はノートの高さで最寄りのサブバンクを使う。
守ること：録音中は割り込まない。自動で再生しない（ヘッドホンの耳元で急に鳴らさない）。モーダルを出さない。

曲をどこに置くか
A　左ペインの上に「曲」採用
曲と行を同じ列に重ねる。曲を選ぶとその曲に要る行に ♫ が付き、行を録ると上の「あと N 行」が減る。原因（行）と結果（曲）が目の動きひとつでつながる。今の「ひかりのあと が歌えるまで」のカードは、この一覧の中の1項目になる。
あと4行
B　中央の下にミニプレイヤー不採用
1曲だけを大きく見せられるが、どの曲が歌えるかの一覧にならない。録音ボタンの近くに再生が並び、Space と ⇧Space の取り違えが起きやすい。
C　右に曲のパネル不採用
一覧は見せられるが、中央の鍵盤と波形が狭くなる（前に広げたばかり）。行と曲が画面の両端に離れ、どの行がどの曲に効くかが追えない。

状態と例外

サブバンクを切り替えた（パンくず ▾）一覧はそのサブバンクの「声色 × 方式」で数え直す。音階はノートごとに最寄りを使う
曲がひとつもない一覧の代わりに「UST / USTX を追加」の1行（S07 へ）
