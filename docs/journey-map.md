# KOERU — Journey Map (As-Is / To-Be)

ビジョン: [product-vision.md](./product-vision.md) ／ 調査資料: [utau_voicebank_creation_research_2026-08-26.pdf](./utau_voicebank_creation_research_2026-08-26.pdf)

> **前提**: KOERU には実ヒアリングがまだない。本 JM はアンケート調査（n=600 / 未経験者 n=63）とビジョンで定義した2セグメントから組み立てた**仮説 JM** である。発話・エピソード・環境描写の多くは `※推測` であり、実際に話を聞いたら差し替える。

## ペルソナ

| | ミナ（新規クリエイター） | ハル（既存クリエイター） |
|---|---|---|
| 属性 `※推測` | 20代前半、専門学校生 | 20代後半、会社員 |
| 背景 | ボカロ曲・UTAU 音源の曲を聴く側。作ったことはない | UTAU 歴5年、音源2本を公開済み。OREMO → 最近 vLabeler に移行 |
| 状況 | 作り方を調べ始めて用語と手順で止まっている | 3本目を作りたいが、往復と再録音の重さを知っていて着手できない |
| シナリオ範囲 | 思い立ってから、諦めるまで | 3本目を作ろうとしてから、止まるまで |

# As-Is JM ①：ミナ（新規クリエイター）

## 【思いつく】

**状況：** 深夜1時、自室のベッド。イヤホンで聴いていた曲の概要欄に「音源：〇〇音源（フリー配布）」。リンクを踏むと、手描きのキャラクターと「利用規約」が並ぶ配布ページ。作ったのは自分と同じくらいの年齢に見える人。`※推測`

**発話 / 内心の声：**
「え、この声、この人が自分で録ってるんだ」
「……私の声でもできるのかな」

**行動：** 配布ページを上から下までスクロールする。作者の X を見に行く。「音源制作」で検索する。

**感情：** 軽い衝撃と、身に覚えのある憧れ。まだ何も始まっていないのに、少しだけ自分の話になっている。

**タッチポイント：** 動画サイトの概要欄、配布ページ、X

**課題：** この瞬間の熱量が一番高い。しかしこの熱量を受け止める入口がどこにもなく、次の一歩が「検索」になっている。

## 【調べる】

**状況：** 翌日の昼休み、スマホ。「UTAU 音源 作り方」で出てきた解説記事を開く。目次に並ぶのは、録音リスト、OREMO、原音設定、setParam、CV / VCV / CVVC、エイリアス、oto.ini、character.txt、文字コード。記事は親切で、丁寧で、長い。`※推測`

**発話 / 内心の声：**
「……ぜんぶ日本語なのに、意味が分からない」
「CVVC って何。まずどれを選べばいいの」
「これ、始める前に決めることが多すぎない？」

**行動：** 記事を最後までスクロールして閉じる。別の記事を開く。用語が微妙に違う。動画を探す。1時間超の解説動画をブックマークして閉じる。

**感情：** 憧れが、じわじわと「これは私向けじゃないかもしれない」に置き換わっていく。誰かに怒られたわけでもないのに、少し恥ずかしい。

**タッチポイント：** 検索、解説記事、解説動画、UTAU 音源制作 wiki

**課題：** 最初に出会うのが**声ではなく用語**になっている。しかも用語の前に「どの方式で作るか」という、まだ判断材料がない選択を迫られる。調査で「作り方が難しそう」36.5%、「作り方が分からない」23.8%。

## 【環境で詰まる】

**状況：** 数日後。やる気を取り戻して録音の項目を読み返す。「静かな環境で」「マイクは〇〇以上推奨」「反響を抑えるため布団をかぶって」。部屋の壁は薄く、隣の物音が聞こえる。手元にあるのはイヤホンマイクだけ。夜は家族がいる。`※推測`

**発話 / 内心の声：**
「そもそも、いつ録るの」
「この部屋で『あ』『い』『う』って何百回も言うの……？」

**行動：** マイクの価格を調べる。5,000円くらいから。カートに入れずタブを閉じる。

**感情：** 熱量が「今じゃないな」に変わる。諦めではなく、延期の形をとる。

**タッチポイント：** 解説記事の録音環境の項、通販サイト

**課題：** 調査で最多の障壁「録音機材や場所がない」46.0%。加えて「何百回も一人で声を出す」という**行為そのものの気恥ずかしさ**（「恥ずかしい・自信がない」22.2%）が重なる。まだ一度も自分の声を録っていないのに、ここで止まる。

## 【止まる】

**状況：** 2週間後。ブックマークした解説動画は未再生のまま。X のタイムラインに、また誰かの新しい音源の告知。試聴すると、ちゃんと歌っている。上手い。`※推測`

**発話 / 内心の声：**
「みんなすごいな」
「……私は、たぶんやらないな」

**行動：** いいねを押す。ブックマークを整理して、UTAU 関連のタブを閉じる。

**感情：** 悔しさですらない。自分は聴く側の人間だ、という静かな確定。

**タッチポイント：** X、他人の音源の試聴

**課題：** **一度も自分の声を録らないまま離脱している。** 自分の声が歌うのを一度も聞いていないので、諦める判断に材料がない。何が楽しいのかを知らないまま、難しさだけを知って帰っていく。

# As-Is JM ②：ハル（既存クリエイター）

## 【作りたくなる】

**状況：** 土曜の昼、自宅のデスク。前に公開した自分の音源を使った曲が上がっていて、通知が来ている。知らない人が、自分の声で知らない曲を歌わせている。何度経験しても、これが一番うれしい。`※推測`

**発話 / 内心の声：**
「うわ、この使い方は思いつかなかった」
「……そろそろ3本目、作りたいな。今度は連続音でちゃんと」

**行動：** コメントに返信する。自分の過去音源のフォルダを開く。前回の録音リストを探す。

**感情：** 純粋な高揚。作りたい理由がはっきりある。

**タッチポイント：** 動画サイトの通知、コメント欄、自分の音源フォルダ

**課題：** ここに動機の問題はない。**動機は満タンで着手する。**

## 【段取りを思い出す】

**状況：** フォルダを開くと前回の作業跡が出てくる。`新規フォルダ`、`oto_backup`、`oto_backup2`、`最終_修正版`、`最終_修正版2`。どれが正解か分からない。録音リストは3種類入っていて、どれを使ったか思い出せない。`※推測`

**発話 / 内心の声：**
「あー……そうだ、これ、前回もここで詰まったんだ」
「今回はどのリストにする？　CVVC にすると原音設定が地獄なんだよな」

**行動：** 過去の自分の作業メモを探す。見つからない。X の過去ポストを遡って、前回どうやったか思い出そうとする。

**感情：** 高揚が、急速に「面倒くささ」に上書きされていく。

**タッチポイント：** ローカルのフォルダ、録音リスト配布サイト、自分の過去ポスト

**課題：** **制作の記憶がプロダクトの中に残っておらず、本人の記憶とフォルダ名に外部化されている。** 5年やっていても、毎回ゼロから段取りを思い出す。

## 【録る】

**状況：** 日曜の午後、家族が出かけている数時間。この時間しか録れない。RecStar を立ち上げ、ガイド BGM に合わせて連続音を録っていく。500音を超えたあたりで喉が疲れてくる。声のトーンが最初と変わっている自覚がある。`※推測`

**発話 / 内心の声：**
「……今の、声変わってきてないか？」
「でも止めたら、次いつまとまった時間取れるか分からない」

**行動：** 止めずに最後まで録りきる。確認は後回しにする。

**感情：** 焦りと、後で後悔する予感。

**タッチポイント：** RecStar、ガイド BGM、録音リスト、マイク

**課題：** 録音中に**品質のフィードバックがない**ので、「後で全部やり直しかもしれない」という不安を抱えたまま録り続ける。時間の制約が、確認を後回しにさせる構造になっている。

## 【原音設定に入る】

**状況：** 翌週の平日夜。vLabeler を開き、録った WAV を読み込む。自動推定はしてくれるが、ズレているものを一つずつ直していく。左手でショートカット、右手でマウス。同じ操作を何百回。`※推測`

**発話 / 内心の声：**
「……これ、あと何時間かかるんだろう」
「先行発声、この音だけ明らかにおかしいな。なんで」

**行動：** 1時間半やって、進捗は全体の2割。保存して閉じる。次の日はやらない。

**感情：** 作業。創作をしている感覚は、この段階には一切ない。

**タッチポイント：** vLabeler、oto.ini、WAV フォルダ

**課題：** ここが**一番時間がかかるのに、一番手応えがない**。声はまだ一度も歌っていない。作っている実感と、作業量が完全に切り離されている。

## 【試唱してやり直しを知る】

**状況：** 数日後、原音設定を半分ほど終えて、我慢できずに OpenUtau に入れてみる。テスト用の UST を読み込む。再生する。自分の声が歌う。うれしい。が、数フレーズ聴いて気づく。後半に録った音だけ、明らかに声が違う。`※推測`

**発話 / 内心の声：**
「……あー。喉やられてたやつ、やっぱりダメだ」
「後半、録り直しか」

**行動：** どこから録り直すべきかを確認するため、録音リストと WAV を突き合わせる。範囲が特定できない。

**感情：** うれしさが一瞬あって、その直後に重さが来る。振り出しではないが、どこまで戻るのかが分からない。

**タッチポイント：** OpenUtau、テスト UST、録音リスト、WAV フォルダ

**課題：** **初めて歌を聴けるのが、全工程のかなり後**。そこで初めて録音の失敗が分かる。失敗の発見が遅いほど、やり直しの範囲が大きく、特定も難しくなる。

## 【止まる】

**状況：** それから3週間、フォルダを開いていない。X には「3本目作ってます」とだけ書いた。進捗を聞かれると気まずい。`※推測`

**発話 / 内心の声：**
「作りたい気持ちはあるんだよな」
「……時間がまとまって取れたら、やる」

**行動：** 何もしない。他の人の新しい音源を試聴する。

**感情：** 罪悪感に近い停滞。嫌いになったわけではない。むしろ好きなまま止まっている。

**タッチポイント：** X

**課題：** **未完成のまま放置された制作物が、次の着手をさらに重くする。** 5年の経験者でも完成に至らない。

# インサイト

1. **「自分の声が歌う」瞬間が、工程の最後に置かれている。** ミナは一度もそこに到達せず、ハルは全工程の8割を終えてからようやく到達する。この体験だけが制作を続ける燃料なのに、最も遠い場所にある。投資と報酬の順序が逆転していて、両者とも「まだ報酬を受け取っていない状態」で離脱する。

2. **失敗の発見が、失敗の発生から遠く離れている。** ハルの喉の疲れは録音中に起きたが、判明したのは数週間後の試唱時だった。工程が分断されているため、フィードバックが工程をまたげない。距離が遠いほどやり直しの範囲は広がり、特定は難しくなり、心が折れる。

3. **制作の文脈が、プロダクトの外側（本人の記憶とフォルダ名）に置かれている。** ハルは5年やっていても、毎回「前回どうやったか」を自分の記憶と `最終_修正版2` から復元している。経験が蓄積されず、2本目も3本目も初回と同じ立ち上げコストを払う。

4. **入口に立つ前に、方式の選択を迫られる。** CV / VCV / CVVC をミナは判断材料なしに選ばされ、ハルは「CVVC は原音設定が地獄」と知っているがゆえに着手を躊躇する。まだ何も録っていない段階で、最も後戻りしにくい決定を要求している。

5. **完成しない制作物が、次の制作を重くする。** ハルの止まった3本目は、単に未完成なのではなく、次に開くときの心理的コストとして積み上がっている。中断が「一時停止」ではなく「負債」になる構造がある。

# HMW と優先度

| # | HMW | 由来 | 優先度 |
|---|---|---|---|
| 1 | どうすれば、まだ録り終えていない声を、その場で歌わせられるか？ | インサイト1 | |
| 2 | どうすれば、報酬（自分の声が歌う）を、投資（録音・設定）より先に届けられるか？ | インサイト1 | **最優先** |
| 3 | どうすれば、録音の失敗をその場で本人に気づかせられるか？ | インサイト2 | |
| 4 | どうすれば、やり直しの範囲を「どこから録り直すか」まで自動で特定できるか？ | インサイト2 | |
| 5 | どうすれば、前回の制作の文脈を、本人の記憶に頼らず引き継げるか？ | インサイト3 | |
| 6 | どうすれば、方式の選択を、判断材料が揃うまで先送りできるか？ | インサイト4 | **最優先** |
| 7 | どうすれば、中断した制作物を、負債ではなく途中経過として置いておけるか？ | インサイト5 | 対象外（動機は背負わない） |

**選定：2 と 6。** どちらも「まだ決めなくていいことを、決めさせない」という同じ性質を持つ。

> **HMW 6 の解釈（重要）**: 「先送り」は**選択肢を閉じることではない**。既定を「あとで決める」にするだけで、選択肢は最初から最後まで開かれている。ユーザーは方式を先に決めることも、決めないことも、任意に選べる。

---

# To-Be の前提

- **最優先 HMW**: 2（報酬を投資より先に）／ 6（方式選択の既定を「あとで決める」に）
- **副次 HMW**: なし
- **To-Be で解決しないもの**: 録音環境（機材・場所）、録音失敗のリアルタイム検知（HMW 3・4）、制作文脈の引き継ぎ（HMW 5）、中断の負債化（HMW 7）。**これらは To-Be でも残す。**

> **技術的前提** `(仮)`: HMW 6 の成立には、録った素材が方式に依存しない中間表現として保持され、後からの追加録音で単独音 → 連続音 → CVVC 相当へ拡張できることが必要。この前提が崩れると To-Be の後半は成立しない。→ コアシーン候補2で検証する。

# To-Be JM ①：ミナ（新規クリエイター）

## 【思いつく】

**状況：** 深夜1時、自室のベッド。概要欄の「音源：〇〇音源」から配布ページへ。手描きのキャラクターと、作者の X。ここまでは As-Is と同じ。`※推測`

**発話 / 内心の声：**
「え、この声、この人が自分で録ってるんだ」
「……私の声でもできるのかな」

**行動：** 「音源 作り方」で検索する。

**感情：** 軽い衝撃と、身に覚えのある憧れ。

**タッチポイント：** 動画サイトの概要欄、配布ページ、X、検索

**As-Isからの変化：** 変化なし。熱量が最も高いのはここ、という構造は変わらない。

## 【始める】

**状況：** 検索結果から KOERU を開く。最初に出るのはプロジェクト作成。名前を入れる欄と、その下にオンボーディングが続く。オンボーディングが示すのは用語の一覧ではなく、短い曲が3つ。それぞれ30秒くらいで、既に誰かの声で歌っている見本が流れている。下に一行だけ、「この曲を、あなたの声で」。`※推測`

**発話 / 内心の声：**
「名前……とりあえずで入れていいのかな」
「録音リストとか、選ばなくていいんだ」
「これ、どれくらいかかるんだろう……8フレーズ？」

**行動：** 名前を入れる。一番短い曲を選ぶ。マイクの許可を出す。画面に最初のフレーズが出る。

**感情：** 身構えていたのが、拍子抜けする。始めていいらしい、と分かる。

**タッチポイント：** KOERU のプロジェクト作成、オンボーディング、課題曲の見本、マイク許可 `※推測`

**As-Isからの変化：** **As-Is の【調べる】フェーズが丸ごと消滅した。** 方式・録音リスト・oto.ini は初期状態では現れない（指定したい人のための項目はたたまれて存在するが、既定は「あとで決める」）。曲を選んだ結果として録る音が決まるので、ミナは方式を選ばずに始められる（HMW 6）。同時に、用語より先に「歌っている見本」が来ている（HMW 2）。

> **決定 D2 の反映（2026-08-26）**: 起動直後をプロジェクト作成にすると決めたため、ミナも名前の入力を経由する。**[Risk]** まだ一度も自分の声を聞いていない段階で音源の名前＝キャラクター名を決めることになり、As-Is でミナが撤退した「声より先に判断を求められる」構造が部分的に復活する。逃げ道（仮名で始める・あとから改名）の設計はオンボーディング側で扱う。詳細は [decisions.md](./decisions.md) の D2。

## 【録る】

**状況：** 夜11時、自室。家族はまだ起きている。イヤホンマイクを口元に近づけて、小さめの声で読む。画面には次に読むフレーズだけが大きく出ている。8フレーズ、5分弱で終わる。`※推測`

**発話 / 内心の声：**
「思ったより少ない」
「小声だけど、大丈夫かな……」

**行動：** 8フレーズを録りきる。録り直したのは2つだけ。

**感情：** まだ半信半疑。ただ「終わった」という感覚はある。

**タッチポイント：** KOERU の録音画面、イヤホンマイク

**As-Isからの変化：** 録る量が数百音から8フレーズになったことで、**まとまった時間と静かな環境を確保する必要が薄れた**（HMW 2 の副次的効果）。ただし **As-Is の課題は完全には消えていない**。マイクの質、部屋の壁の薄さ、小声で録ることへの不安は残る。KOERU はこの段階で品質の良し悪しを教えない（HMW 3 はスコープ外）。ミナは不安を抱えたまま次に進む。

## 【初めて歌う】

**状況：** 録り終えた画面に「聴いてみる」とだけ出ている。押す。数十秒の待ち時間のあと、さっき選んだ曲が流れ始める。歌っているのは、自分の声。`※推測`

**発話 / 内心の声：**
「……えっ」
「うわ、私だ。私の声だ」
「なんか、私よりちょっと上手い」

**行動：** 最初から3回聴き直す。イヤホンを外して、スピーカーでもう一度流す。スクリーンショットを撮る。

**感情：** 驚きと、自分の声への面白さ。恥ずかしさが、初めて「かわいさ」寄りに転ぶ。

**タッチポイント：** KOERU の試唱画面

**As-Isからの変化：** **As-Is には存在しなかったフェーズ。** ミナは As-Is では一度もここに到達しなかった。投資（8フレーズ・5分）より報酬（自分の声が歌う）が先に来ている（HMW 2）。**ここが As-Is / To-Be の最大の差分。**

## 【広げる】

**状況：** 翌日。KOERU を開くと「いま歌える曲：1」と出ている。その下に、あと何フレーズ録れば次の曲が歌えるかが並んでいる。方式の指定欄はたたまれたままで、ミナはまだ開いていない。`※推測`

**発話 / 内心の声：**
「これ録ったら、この曲も歌えるようになるんだ」
「昨日のより長い曲、やってみようかな」

**行動：** 次のフレーズ群を録る。歌える曲が2つになる。

**感情：** 昨日の驚きが、続ける理由に変わっている。

**タッチポイント：** KOERU のプロジェクト画面

**As-Isからの変化：** 進捗が「録音リストの消化率」ではなく「歌える曲の数」で表現されている。追加録音が積み上がった結果として内部的には単独音から連続音へ音源が育つが、**ミナは既定のまま進んでいるのでその変化を意識しない**（HMW 6）。方式は最初の選択ではなく、後からの結果になっている。

# To-Be JM ②：ハル（既存クリエイター）

## 【作りたくなる】

**状況：** 土曜の昼、自宅のデスク。自分の音源を使った曲の通知。知らない人が、自分の声で知らない曲を歌わせている。`※推測`

**発話 / 内心の声：** 「……そろそろ3本目、作りたいな」

**As-Isからの変化：** 変化なし。動機は As-Is でも満タンだった。KOERU はここに手を入れない。

## 【再開する】

**状況：** KOERU で新しいプロジェクトを作る。必須の入力は音源の名前だけ。その下に「方式を指定する」という項目がたたまれている。開くと単独音・連続音・CVVC が並んでいて、「あとで決める」に既定でチェックが入っている。`※推測`

**発話 / 内心の声：**
「お、ちゃんと選べるようになってるんだ」
「今回は連続音って決めてるから、先に指定しとくか」
「……いや、既定のままでも後から選べるのか。どっちでもいいのは楽だな」

**行動：** 項目を開いて連続音を指定する。指定すると録音の順序がそれに合わせて組み替わる。（既定のまま名前だけで始めることもできる）

**感情：** コントロールを取り上げられていない安心。既定に従っても、外れても、どちらも正規のルート。

**タッチポイント：** KOERU のプロジェクト作成画面、方式指定（折りたたみ）

**As-Isからの変化：** As-Is では方式選択が**着手の前提条件**だった。To-Be では**既定が「あとで決める」に変わっただけで、選択肢は最初から最後まで開かれている**（HMW 6）。先に決めたい熟練者は先に決められ、その場合は録音順序が最適化される。決めなかった場合も後から書き出し時に選べる。方式は「不可逆な前提」から「いつでも触れる設定」になった。
ただし **インサイト3（制作の文脈が本人の記憶に外部化されている）は解決していない**。「前回どう録ったか」の手がかりは KOERU の中にまだない（HMW 5 はスコープ外）。

## 【少しずつ録る】

**状況：** 平日の夜、30分だけ。家族が起きている時間でも、フレーズ単位なら区切って録れる。今日は20フレーズ。喉が疲れる前にやめる。`※推測`

**発話 / 内心の声：**
「今日はここまででいいや」
「まとめて録らなくていいの、楽だな」

**行動：** 途中で保存して閉じる。翌々日、また30分録る。

**感情：** 作業ではあるが、重くない。

**タッチポイント：** KOERU の録音画面

**As-Isからの変化：** 「まとまった数時間を確保して一気に録りきる」必要がなくなったため、**喉の疲れによる声質の変化そのものが起きにくくなった**（HMW 2 の副次的効果）。ただし **これは予防であって検知ではない**。声がブレたときに KOERU が録音中に指摘してくれるわけではない（HMW 3 はスコープ外）。インサイト2 は構造的には残っている。

## 【早い段階で歌わせる】

**状況：** 2回目の録音を終えた時点で、KOERU が「いま歌える」と表示する。テスト曲を再生する。まだ音が足りないので歌えるのは短いフレーズだけだが、確かに新しい声で歌っている。`※推測`

**発話 / 内心の声：**
「お、もう歌うんだ」
「……この声、思ってたより低いな。今回は低めで統一するか」

**行動：** 歌わせた結果を聴いて、残りの録音のトーンを決める。

**感情：** 5年やってきて初めて、**原音設定の前に自分の音源の性格が分かる**。

**タッチポイント：** KOERU の試唱、テスト曲

**As-Isからの変化：** As-Is では試唱が全工程の8割地点にあり、判明するのは常に「失敗」だった。To-Be では試唱が序盤にあり、判明するのは「この音源はこういう声だ」という**設計情報**になっている（HMW 2）。報酬が前に来ただけでなく、意思決定の材料としても機能している。

## 【方式を確定して書き出す】

**状況：** 録音が進み、歌える範囲が広がってきた。KOERU が「連続音として書き出せる状態になりました」と伝えてくる。書き出し設定を開くと、単独音・連続音の両方が選べる。上級モードを開けば oto.ini の数値も触れる。`※推測`

**発話 / 内心の声：**
「これ、単独音でも出せるのか」
「両方出しておくか。使う人によって好みあるし」

**行動：** 両方の形式で書き出す。細かい先行発声だけ、気になる音を手で直す。

**感情：** 作業の主導権が自分にある感覚。隠されているのではなく、必要になったら開けられる。

**タッチポイント：** KOERU の書き出し画面、上級モード、OpenUtau

**As-Isからの変化：** 方式が**不可逆な前提から、可逆な出力オプションに移動した**（HMW 6）。先に指定していた場合はその方式が既定として選ばれ、指定していなければここで選ぶ。どちらの経路でも最終的な選択肢は同じ。

## 【残るもの】

**状況：** 3本目は無事に書き出せた。ただ、このあと配布ページを作り、規約を書き、紹介動画を用意する必要がある。ここは As-Is と変わっていない。`※推測`

**発話 / 内心の声：** 「作るとこまでは来たけど、公開はまた別作業だな」

**As-Isからの変化：** **変化なし。今回の HMW では扱っていない。** 公開・パッケージングの負荷、中断の負債化（インサイト5）、制作文脈の引き継ぎ（インサイト3）は To-Be でも残っている。

# コアシーン候補

## 候補1：【始める】→【初めて歌う】— 説明ゼロで録り始めて、5分で自分の声が歌う

- **選定理由**: As-Is との差分が最大（ミナはこのフェーズ自体が存在しなかった）。感情が最もポジティブに振れる。ビジョンの一行と Create before configure が成立するかがここで決まる。
- **検証したいこと**: 説明なしで録音を開始できるか。最初の試唱までの実測時間。最も重要なのは、**イヤホンマイク・小声・生活音ありという現実的な条件で録った8フレーズが、聴いて嬉しい歌になるか**。ここが破綻すると、報酬を先に届ける設計そのものが逆効果になる（がっかり体験が最初に来る）。

## 候補2：【広げる】/【方式を確定して書き出す】— 追加録音で方式が後から育つ

- **選定理由**: 技術的な不確実性が最も高い。方式非依存の中間表現と段階的拡張が成立しなければ HMW 6 は絵に描いた餅になる。ビジネス的にも、ここが競合（RecStar + vLabeler の組み合わせ）に対する唯一の構造的な差になる。
- **検証したいこと**: 単独音相当の素材から追加録音で連続音へ拡張したとき、品質が実用に耐えるか。そして**ミナが実際に「広げたく」なるか**（初回の驚きが2回目の録音の理由になるか）。

## 候補3：ハル【再開する】— 既定が「あとで決める」であることが、熟練者に正しく伝わるか

- **選定理由**: 選択肢は最初から開かれているので「勝手に決められた」という拒否反応のリスクは下がった。残る論点は**既定の伝わりやすさ**。熟練者が「選べない」と誤解した瞬間に離脱する。また、先に決めた人と決めなかった人で体験に差が出ないかは、設計上まだ答えが出ていない。
- **検証したいこと**: 作成画面で「あとで決められる」「今決めてもいい」の両方に気づけるか。**先に決めなかった人が後から不利にならないか**（先決めすると録音順序が最適化されるなら、決めなかった人は余分に録ることになるのか）。折りたたみを開く熟練者の割合。
